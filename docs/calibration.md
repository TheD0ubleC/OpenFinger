# 校准

OpenFinger 的校准分两块：手指输入校准和虚拟控制器偏移。

手指输入校准处理 ADC 到弯曲值的映射。虚拟控制器偏移处理真实控制器和虚拟手之间的空间误差。

这两个问题不要混着调。

## 手指输入

固件上报的是原始 ADC。GUI 和 Service 需要把它转换成可用的弯曲值。

常见误差来源：

- 传感器固定位置不同
- 手套材料回弹不同
- 手指完全伸直时 ADC 不一致
- 弯曲到极限时传感器已经饱和
- 线材晃动导致短时噪声

推荐流程：

```text
连接设备
确认左右手角色
确认五指通道有响应
记录伸直值
记录握拳值
保存配置
看实时状态页
```

不要一开始就调滤波。原始范围没调好时，滤波只会把问题藏起来。

## 虚拟控制器 6DoF 偏移

6DoF 偏移给左右手分别配置：

```text
位置 X / Y / Z，单位 m
旋转 Pitch / Yaw / Roll，单位 degree
```

它用于修正虚拟手和真实控制器之间的装配误差。例如控制器绑在手背、手腕或外壳上，SteamVR 给出的控制器位姿不等于手掌位姿。

## 调整建议

位置偏移从小值开始：

```text
0.005 m
0.010 m
0.020 m
```

旋转偏移从小角度开始：

```text
1°
2°
5°
```

一次只改一个轴。改完戴上设备，在 SteamVR 里看：

- 手掌中心是否贴近真实手掌
- 握拳时手指方向是否自然
- 左右手是否对称
- 抓取物体时是否偏离明显

不要为了某一个姿势看起来正确，把偏移调得很大。大偏移通常会让其他姿势更差。

## 轴和单位

位置单位是米。`0.01` 表示 1 厘米。

旋转单位是角度。界面显示 Pitch / Yaw / Roll，但实际效果取决于 driver 的应用顺序和 SteamVR 坐标系。调试时按视觉结果判断，不要只看数学名词。

## 不推荐

- 用 6DoF 偏移修手指弯曲问题
- 用很大的旋转偏移补硬件安装方向错误
- 左右手复制同一套参数后不再检查
- 改完偏移不重启相关运行时就判断结果

如果硬件安装方向差太多，应该改安装方式或 driver 的基础姿态，不要靠校准参数硬拉。

## 保存位置

GUI 保存的是本机配置。偏移不写入固件。

这意味着：

- 换电脑需要重新配置或复制配置文件
- 刷固件不会清掉偏移
- 同一副手套在不同控制器固定方式下需要不同偏移

## 排查

### 手在 SteamVR 里整体偏移

看 6DoF 位置偏移。先把旋转清零，只调位置。

### 手方向不对

看旋转偏移。先调一个轴，确认方向，再调另一个。

### 手指弯曲不对

不要调 6DoF。回到手指输入校准。

### 左手正常，右手很怪

检查左右手角色、设备绑定和 ControllerBridge 输入。不要只看 GUI 里的左右手标题。
