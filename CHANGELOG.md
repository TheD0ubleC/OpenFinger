# Changelog

## 0.1.0

Initial cleaned OpenFinger repository baseline.

- Removed deprecated `OpenFingerGUI` dependency and temporary Python prototype files.
- Added unified `VERSION` and `PROTOCOL_VERSION` files.
- Added generated version outputs for C#, C++/CMake, firmware, and SteamVR manifests.
- Rebuilt `x.py` as the single build, firmware, packaging, cleaning, and version-generation entry point.
- Added documentation for architecture, protocol, build flow, versioning, and cleanup decisions.
- Cleaned checked-in build/cache artifacts from the source tree.
